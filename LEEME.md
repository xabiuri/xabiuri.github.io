# Publicar tu blog (usuario: xabiuri)

Tu blog estará en: https://xabiuri.github.io/

1. En github.com: botón "+" (arriba a la derecha) → "New repository".
2. Nombre del repositorio: EXACTAMENTE `xabiuri.github.io`. Déjalo en Public. Pulsa "Create repository".
3. En la página que aparece, pulsa el enlace "uploading an existing file".
4. Arrastra todo el contenido de esta carpeta (index.html, style.css, sobre-mi.html, sitemap.xml, robots.txt y la carpeta entradas). Pulsa "Commit changes".
5. Settings → Pages → Source: "Deploy from a branch" → Branch: main / (root) → Save.
6. En 1-2 minutos abre https://xabiuri.github.io/

Después, para Google: search.google.com/search-console → añade https://xabiuri.github.io/ → verifica → Sitemaps → envía `sitemap.xml`.
